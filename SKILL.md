# eliza-trader-starter

eliza-trader-starter is a ready-to-fork ElizaOS agent wired to Orkid's swap tools: it ships the plugin config, example prompts, and gasless execution defaults so a trading agent can quote and route in minutes.

## When to use

Bootstrapping an ElizaOS trading agent on Orkid infrastructure.

## Install

```
gh repo clone orkid-labs/eliza-trader-starter
```
